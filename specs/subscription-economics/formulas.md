# Формулы и правила расчёта

Обозначения: p - цена в месяц, m - маржа (доля, 0 < m <= 1), c - отток в месяц (доля, 0 < c <= 1), k - CAC, R - порог LTV/CAC, T - порог окупаемости в месяцах.
Ввод: маржа и отток вводятся в процентах, внутри делятся на 100. Десятичный разделитель в вводе: запятая или точка.

## Основные цифры

- Срок жизни клиента (мес) = 1 / c
- LTV = p * m / c
- LTV/CAC = LTV / k
- Окупаемость (мес) = k / (p * m)
- Вердикт "масштабировать": LTV/CAC >= R и окупаемость <= T. Иначе "пока нет". Границы включительно.

## Допустимый ввод

p > 0, 0 < m <= 100%, 0 < c <= 100%, k > 0, R > 0, T > 0. Пустое поле, текст, ноль и отрицательные значения там, где нужно > 0, - ошибка ввода с текстом причины. Пока ввод некорректен, цифры и вердикт не показываются.

## Предупреждение о нереалистичном LTV

Если c < 1% в месяц (срок жизни больше 100 месяцев), показывается предупреждение: LTV держится на допущении, что клиент не уходит почти никогда. Цифры при этом показываются.

## Что нужно изменить (расчёт по каждому показателю отдельно, остальные три не меняются)

Нужное значение - минимальное изменение, при котором выполняются оба порога сразу.

- Цена: p* = max(R * k * c / m, k / (T * m)). Нужно, если p* > p.
- Маржа: m* = max(R * k * c / p, k / (T * p)). Если m* > 1 (100%), "недостижимо".
- CAC: k* = min(p * m / (R * c), T * p * m). Нужно, если k* < k.
- Отток: c* = p * m / (R * k). Окупаемость от оттока не зависит: если окупаемость уже хуже T, изменением оттока вердикт не исправить, "недостижимо".

Нужное значение округляется до 2 знаков в сторону выполнения порога: цена и маржа вверх, CAC и отток вниз. Так показанное значение, подставленное обратно, даёт "масштабировать". Изменение в процентах считается от показанного (округлённого) нужного значения: (нужное_округлённое - текущее) / текущее * 100, округление до 2 знаков. Если вердикт "масштабировать", блок "что сдвинуть" не считается, показывается "изменения не нужны".

## Порядок "с чего начать"

Оценка = |изменение в %| * вес трудности. Вес: легко 1, средне 2, трудно 3. Меньше оценка - проще. "Недостижимо" в порядок не входит и идёт в конце. При равных оценках порядок: цена, CAC, отток, маржа. Трудность по умолчанию "средне".

## Округление

В показе: деньги и LTV до 2 знаков, LTV/CAC до 2 знаков, месяцы до 1 знака, проценты до 2 знаков. Правило: половина вверх (3,125 -> 3,13). Сравнения с порогами идут по неокруглённым значениям с относительным допуском 1e-9 (значение, отличающееся от порога меньше чем на 1e-9 от порога, считается равным ему).

## Показ значений рядом с порогом

Если округлённое значение LTV/CAC, окупаемости или процента изменения при показе совпало бы с порогом (или с нулём для процента), но вердикт его не принимает, показывается столько знаков, чтобы показанное значение отличалось от порога (не больше 6 знаков). Пример: LTV/CAC 2,997 при пороге 3 показывается как "2,997", а не "3,00".

## Ввод

Принимаются цифры с одним десятичным разделителем (запятая или точка), пробелы по краям и внутри игнорируются. Запись вида одна-три цифры, разделитель, ровно три цифры ("1,000", "1.000", "12.500") отклоняется как неоднозначная (тысячи или дробь) с просьбой ввести число без разделителя тысяч или с другим числом знаков. Знак «%», экспоненциальная запись, Infinity, несколько разделителей - ошибка ввода. Пороги R и T проверяются так же, как четыре показателя: ошибка у поля порога скрывает цифры и вердикт.

## Порядок при равенстве

Оценки сравниваются после округления до 2 знаков; при равенстве - порядок цена, CAC, отток, маржа.

## Сочетания

Предупреждение о малом оттоке показывается вместе с любым вердиктом, в том числе с «изменения не нужны».
