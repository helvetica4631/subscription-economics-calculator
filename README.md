# Калькулятор экономики подписки

Сайт для продакта, который хочет быстро проверить, можно ли масштабировать платное привлечение клиентов. Вводишь цену подписки, маржу, отток и стоимость привлечения клиента (CAC). Сайт показывает вердикт «масштабировать» или «пока нет», каждую цифру с формулой и пояснением и, если вердикт «пока нет», насколько нужно изменить каждый показатель, чтобы дойти до порога.

Всё считается в браузере. Ничего не сохраняется и не отправляется в сеть.

## Как открыть
В интернете: https://helvetica4631.github.io/subscription-economics-calculator/

Локально: двойным щелчком по файлу `index.html` в корне проекта: он откроется в браузере. Больше ничего не нужно, интернет не требуется. Файл можно переслать отдельно.

## Для тех, кто меняет расчёты
Логика лежит в `src/`. После правок пересоберите страницу командой `npm run build`, проверки запускаются командой `npm test` (нужен Node.js 22, он уже установлен).
